## 4. Architecture technique (pour reprendre)

### Modèle de données du texte enrichi
- **Annotation** : `{x, y, t, s, c, al?, bg?, f?, ol?}`
  - `t` = contenu, avec **HTML inline restreint** : `<b> <i> <u> <s>` et `<span style="color:#hex">`.
  - Lignes séparées par `\n`. En tête de ligne : **marqueur d'alignement** `<c>`/`<r>`/`<l>` (optionnel) puis **marqueur de liste** `- ` ou `1. ` (texte brut).
  - `s` = taille en % de carte (défaut 1.5) · `c` = couleur par défaut · `al` = align par défaut du bloc · `bg` = boîte sombre · `f` = police (`mono`/`sans`/`serif`) · `ol` = contour (1 forcé / 0 off / absent = auto).
- **Label de pastille** : `o.label` = même HTML inline (vide = nom en gras). Sérialisé via `pinMeta` (`escJs`).

### Fonctions clés du socle (`sortie-map-core.js`, exposées sur `window.SORTIE`)
`parseInline(html)` → runs `[{t,b,i,u,st,c}]` · `parseRich(o)` → lignes `[{list,align,prefix,runs}]` (marqueurs détectés sur le **texte réel, hors balises**) · `runsToHtml(runs)` (HTML sûr) · `stripRuns(runs,n)` · `textFont/textAdv/textAlign/textBold/textItalic/textOutline/textDeco` · `textsConst` (sérialise `TEXTS`/`TEXTS_B`, gras/ital/etc. **inline**, pas au niveau bloc) · `pinMeta` (label via `escJs`).

### Studio (`map-studio.html`)
- **Éditeur enrichi partagé** : `normalizeRich` (contenteditable → chaîne, capte l'alignement par `<div style=text-align>`), `_inlineHtml`, `_alignMark`, `richToEditableHtml`, `richToolbarHtml`, `wireRich` (execCommand bold/italic/underline/strike + justify + foreColor + **casse via `transformCase`**), `applyListRich` + `_caretLineByMark` (ligne du curseur par marqueur).
- **Rendu Konva par run** : `makeRunNodes` (un `Konva.Text` par segment stylé, faux-bold), `relayoutText` (annotations), `buildLabelContent`/`pinLabel` (labels).
- **Édition sur la carte** : `openMapEdit(cfg)` / `closeMapEdit` / `positionMapEdit` (ancre + bascule + clamp) / `editTextOnMap` / `editLabelOnMap`. Popover = `#mapedit > .mecard` (barre `#mped_tb` + zone `#mped`).
- **Historique** : `commit`/`commitSoon`/`undo`/`redo`/`snapState`/`restoreState`, seed via `resetHistory` au boot / changement d'étage / rechargement.
- **Modales** : `askConfirm(msg,{title,ok,danger})` → Promise.
- **Sauvegarde `data.js`** : remplacement bloc par bloc par regex (`const NAME=[...]`), format STABLE. Le HTML inline (avec guillemets doubles) survit dans la chaîne JS entre apostrophes.

### Guide (`app.js` + `style.css`)
- `txtSvg(o)` : annotations en SVG, **une balise `<text>` par ligne** (alignement propre) + **`<tspan>` par run** (styles inline).
- `poiLabel(o)` : labels en HTML inline sûr (`runsToHtml`), alignement par ligne via `<span display:block text-align:…>`.
- Tailles : `.poi.boss/pack/mid` = 13.5/9.5/7 % ; `.ovmap` est un **container query** et `.ovmap .plabel` est en `cqw` (relatif à la carte) ; `--ovlblm` (marge) calculé dans `app.js`.

## 5. Interaction utilisateur (mémo)

- **Créer un texte** : outil Texte (T) → clic sur la carte → le popover s'ouvre, on écrit.
- **Éditer un texte** : clic dessus (re-clic rouvre) · **déplacer** : glisser.
- **Éditer un label** : clic sur la pastille (sélection) puis re-clic, ou double-clic, ou bouton « Éditer le label sur la carte » dans l'inspecteur.
- **Valider** : cliquer ailleurs (garde la sélection) ou **Échap**.
- **Barre d'outils flottante** : G / I / U / S · alignement L/C/R · **AA / aa / Aa** · couleur + teintes · puce `•` / numéro `1.` / normal `Aa`.
- **Inspecteur (à droite)** : réglages « bloc » du texte (police, taille, fond, contour, position, supprimer) + bouton « Écrire sur la carte ».
