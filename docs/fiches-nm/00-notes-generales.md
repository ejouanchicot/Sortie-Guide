# Sortie — Notes générales

> Informations transversales aux 8 NM de Sortie (Outer Ra'Kaznar U).
> Issues de la recherche communautaire : FFXIAH, forums Square Enix officiels, BG-Wiki, FFXIclopedia.

---

## ⭐ Déclaration officielle des devs

> **Tous les boss du Lower Sortie possèdent une « gimmick » intégrée** permettant de réduire les dégâts, retarder une ability, ou annuler un changement de mode.
> Le succès dépend de l'exploitation de ces gimmicks pour **conserver ses seals**. Les ignorer rend les combats bien plus durs que prévu.

---

## Les 8 NM en un coup d'œil

| Lettre | Lv.135 | Lv.145 | Famille | Gimmick centrale |
|---|---|---|---|---|
| **D / H** | **Degei** | **Aita** | Humanoid (RUN/DRK) | Faiblesse élémentaire changeante ; procs → retarde/affaiblit **Vivisection** |
| **A / E** | **Ghatjot** | **Dhartok** | Amorph Plovid (WAR/BLM) | **Absorbe Water** ; **Taint** cumulatif à nettoyer |
| **B / F** | **Leshonn** | **Gartell** | Elementals Macuil (MNK/BLM) | **Aura des mains** Wind/Thunder ; procs → retire les stacks de DT |
| **C / G** | **Skomora** | **Triboulex** | Undead Defiant (DRK/BLM) | **Absorbe Dark** ; hits **Light** → réduit **Setting the Stage** |

---

## Ordre de run recommandé

> **D → H → A → B → C → G → F → E → Aminon**

**Raison de commencer par D :**
> *"You want to do your 2HRs on the most difficult bosses. So if you do D (Degei) first, you should have Soul Voice etc. back to do Aita (H Boss)."*

### Repères d'horloge (temps restant)

| Étape | Temps restant |
|---|---|
| Après **Degei** (D) | ~53 min |
| Après **Aita** (H) | ~47 min |
| Après **Leshonn** (B) | ~43 min |
| Après **Skomora** (C) | ~35 min |
| Arrivée sur **Dhartok** (E) | 14-17 min |
| **Dhartok** mort | ~15 min |
| **Aminon** mort | 5-8 min |

**Durée totale annoncée :** 42-46 min (Normal) · 54-58 min (Hard).

### Objectifs de temps par boss

| Boss | Objectif |
|---|---|
| Degei, Leshonn | ≤ 4 min |
| Aita, Gartell, Triboulex | ≤ 6 min |
| Skomora, Ghatjot, Dhartok | < 3 min (Skomora), ~1-4 min (Ghatjot/Dhartok) |

⚠️ Témoignage sur les boss du sous-sol : *"If the fight goes on for **60+ seconds** you're risking someone getting blasted"* et *"if it's over **120 seconds**, it's a disaster."* Ces boss sont conçus pour un burst compressé, contrairement à Aminon (5-20 min).

## Ra'Kaznar Metal

- **Un Metal par secteur (A à H)**, chacun avec un effet dédié sur le boss correspondant.
- Description item commune : *"A nondescript sheet of metal of an obsidian hue. **Protects against attacks of monsters found beyond Diaphanous Gadget #X**."*
- **L'objet disparaît à la mort du boss.**

| Metal | Boss | Effet |
|---|---|---|
| **A** | Ghatjot | Taint → **Poison retirable**. Obtenu en tuant les **Acuex de la zone A avec des sorts de feu mono-cible** — peu coûteux, quasi toujours rentable |
| **B** | Leshonn | Bloque les additional effects **Stun et Gravity** des attaques mêlée |
| **C** | Skomora | **Haunted → Curse** (nettoyable par Holy Water / Cursna) |
| **D** | Degei | Bloque les **status effects de ses TP moves** |
| **E** | Dhartok | Taint → **Poison retirable**. Obtenu au **coffre de l'Esurient Botulus** (boss C, ~1/4) — ⚠️ le guide mage recommande de **s'en passer** : le détour *"wastes time for most groups"* |
| **F** | Gartell | *"Weakens attacks from Gartell"* — mécanisme exact **non documenté** |
| **G** | Triboulex | **Haunted → Curse** (ne fait que réduire la vitesse de déplacement). Semble **obtenu automatiquement** en tuant **Gyvewrapped Naraka** |
| **H** | Aita | ⚠️ **Effet non confirmé** — spéculation : bloque au moins les status effects des TP moves |

---

## Ne pas confondre : Seal ≠ Metal

- Le **Ra'Kaznar Seal** est un objet de coffre du secteur Basement qui **réduit la puissance de Banes of Tartarus d'Aminon**. Il n'a rien à voir avec les Metals.
- Le **Seal Vow** se sécurise sur **Degei (D)** pour être garanti sur Aminon.
- **Durabilité des seals :** elle décroît en continu pendant le run. Seule confirmation officielle d'un levier : sur **Aita**, quand Vivisection passe sous le seuil de dégâts, **ses ailes disparaissent et le taux de décroissance du seal ralentit**.

## Compositions de groupe types

| Usage | Composition |
|---|---|
| **9 boss (testé)** | PLD/WHM · COR/DRK · GEO/DRK · RDM/DRK · BRD/DRK · DNC/DRG |
| **Guide communautaire SE** | PLD / DNC / COR / RDM / GEO / BRD (variante DRK à la place du DNC) |
| **Polyvalent boss tour** | RUN / BLU / SCH / WAR / BRD / COR |
| **Mage burst** | RUN / COR / GEO / SCH + 2 (BLM et/ou SCH) — *"double SCH so you don't run out of strats"* |
| **Melee zerg** | WAR/SAM/GEO/WHM/BRD/COR · SAM/WAR/RDM/COR/BRD/WHM |
| **Route 6-box** | DD, DD, Heal, BRD, COR, BLU — split en 3 routes (verte / bleue / rouge) qui convergent |

- Les sous-jobs **/DRK** massifs servent à **Absorb-TP** : tout le monde équipe du gear Absorb-TP et on alterne les casts pour maintenir Aminon sous 300 TP.

## Rendement

- Groupes réguliers : **26-29 objectifs** pour **17 000 – 20 000 gallimaufry** par run.
- Run basement solo bien mené : **~20 000 gallimaufry**.

## Note d'actualité importante

> Les anciennes contraintes liées aux **Prime Weapons Stage 4** (durcissement des boss E/F/G/H selon la simple présence d'un Stage 4 dans l'inventaire) **ne s'appliquent plus** :
> *"Most of the information in this thread is now outdated, as the **EFGH boss enrages have been removed** and **Aminon is now a toggle**."*

Sur Triboulex, un Stage 4 modifiait **uniquement le timing des abilities** (Setting the Stage vers 75 % HP), jamais leur puissance ni les résistances.

## ⚠️ Limites de cette recherche

- Les **pages Talk de BG-Wiki** (`Talk:Degei`, `Talk:Aita`, `Talk:Leshonn`, `Talk:Gartell`, `Talk:Skomora`, `Talk:Triboulex`) renvoient un **403 systématique** en accès automatisé. Ce sont probablement les meilleures sources de témoignages restantes — **à consulter manuellement**.
- **Aucune donnée chiffrée de drop rate d'Old Case** n'a pu être vérifiée.
- **Reddit r/ffxi** et **BlueGartr** n'ont rien donné d'exploitable sur ces NM.
- La page **BG-Wiki « Sortie Strategies »** existe mais ses sections boss sont **vides / work in progress**.
- Les guides commerciaux type **mmogah.com** sont de fiabilité inégale — leurs infos sont marquées comme telles dans les fiches.
